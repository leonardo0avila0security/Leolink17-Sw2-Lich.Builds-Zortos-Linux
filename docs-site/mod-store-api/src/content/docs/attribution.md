---
title: Attribution and licensing
description: Credit authors and respect each original source's distribution terms.
---

Show the listing's `author` and link to its original `source_url` in your
mod UI. For GameBanana, show additional contributors from `external.credits`
when available. Use the original listing URL rather than a raw file URL for
the player-facing link. Keep the link available when automatic installation
is offered, and make it the primary action for link-only entries.

Download files from the original source. Don't rehost files or previews, and
don't bypass login prompts, file restrictions, or access blocks. A catalog
entry, working download URL, or published checksum does not grant
redistribution rights.

For GitHub listings, follow the README and any per-file terms at the
revision linked in `source_url`. The reviewed revisions of the five
repositories don't declare redistribution terms. The catalog uses
`NOASSERTION` for that case. It is not a license grant. Some repositories
also document additional conditions for particular mods.

See [Support and takedowns](/contact/) if a listing is missing attribution or
should be removed.
