## Integration support

Open a [Lichii GitHub issue](https://github.com/zortos293/Lichii/issues) or
contact **zortos** on the [Lichii Discord](https://discord.gg/lichii). Include your emulator name and
version, the endpoint and query, whether you sent `github-v1`, and the status
code or a small error response. Don't post user data or files.

## Takedowns and attribution corrections

Mod authors and rights holders can request removal or a credit correction
through [Lichii GitHub issues](https://github.com/zortos293/Lichii/issues) or
by contacting **zortos** on the [Lichii Discord](https://discord.gg/lichii). Include the catalog listing
ID or URL, the original source link, your connection to the work, and what
you want changed. Use Discord if you need to share nonpublic details.

Removing an item from this catalog does not remove it from GameBanana or
GitHub. Contact the original host about the files it serves.
